  (`test_exports_layout_emails_injection_and_audit`), and SPA breakdown rendering.

  `test_verbatim_email_and_missing_email_issue`,

  reclassification or an audited override writer; this is intentionally Partial.
- PKG-01/02/04: build_zip.py, test_build_zip.py helper assertions, launcher
  `test_lock`/`test_launch` and database backup/migration tests establish parts
  of the contract. No model-complete native locked-laptop smoke was inferred.
- **Masked-snapshot email check (OUT-10):** validation compares the persisted masked
  scoring snapshot exactly to the mask of the current CT email (legacy rows use
  live serialization). It is case-sensitive; test_req_out_02_email_snapshot_case_is_not_normalized
  exercises it. Raw historical email bytes are not persisted, so changes confined
  to hidden characters cannot be proven equal. A green panel is not proof of raw
  byte equality. Actual verbatim CT copying is separately tested in ingestion/export.
- Existing Admin/security guides have stale Pending notes: approval/candidate routes
  arrived in #18; instance-default model support in #23; lockout UI in #31. Do not
  repeat those as current missing features. SECURITY_REVIEW P4/P5 and storage/native
  limitations remain; this inventory does not approve their deferral.
- PR provenance was checked against `git log --first-parent origin/main -- PFC`
  and path-limited ingestion/matching/frontend/packaging history, then
  `gh pr list --state merged --limit 100 --json number,title,mergedAt`.
  All linked PRs are merged. No open implementation branch is credited.
- Runtime integration check: start_run calls file-backed load_domain_config;
  OCC reference/synonym writers update SQLite only. An active scoring template
